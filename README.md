SAYLESS 是一个专注简历制作与维护的工具。它只做一件事：让你在同一个界面里编辑内容、调整版式、实时预览，并在需要时导出或分享。没有投递管理，没有面试流程，也没有 AI 代写——注意力只留给简历本身。

## 一条直截了当的路径

1. **打开即用**：未登录也能直接编辑模板简历，内容自动保存在当前设备。
2. **结构化维护内容**：教育、实习、项目按模块填写，改一处立刻在预览中出现。
3. **调整版式与细节**：分区顺序、展示配置、间距与照片，都在右侧配置里完成。
4. **导出与分享**：随时导出 PDF、复制 Markdown，或生成公开链接分享给任何人。
5. **登录后跨设备**：同一个账号可以维护多份简历、克隆版本并随时切换。

## SAYLESS 能做什么

### 边写边看

左侧编辑结构化内容，中间是 A4 预览，右侧调整展示配置。内容与版式同步变化，不需要在多个工具之间来回切换。

### 为不同机会准备不同版本

登录后可以创建、克隆和切换多份简历。简历是独立资产，按自己的节奏维护，不与任何外部流程绑定。

### 导出与分享

一键导出 PDF、复制为 Markdown，或开启公开分享生成链接。访客可以查看公开简历，但不会接触任何真实的私有内容。

## 访客与账号

- **访客**：基于浏览器匿名设备 id 编辑模板简历，数据只保存在当前浏览器，不与其他设备或账号互通。
- **登录用户**：通过 iNon 统一账号登录，简历数据严格归属自己的 `userId`。

## 产品原则

- **专注**：只做简历，不引入投递、面试、题库、公司或批次管理。
- **个人空间优先**：不引入团队、共享工作区或协作权限。
- **完整功能免费**：不设置付费墙、使用配额或账户等级。
- **工具而非替代者**：不调用 LLM，不提供 AI 润色或自动生成。
- **数据彼此隔离**：每位用户的简历严格归属于自己的账户，访客数据按设备隔离。

## 技术概览

SAYLESS 使用 Next.js 和 React 构建并部署在 Vercel，数据通过 Cloudflare Worker 网关写入 Cloudflare D1，登录由 iNon 统一账号提供。浏览器不会直接访问数据库，认证、业务规则和数据访问均在服务端完成。
